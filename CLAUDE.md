# Project: Noted Haven

Noted Haven is a customizable stationery print shop (notebooks, notepads, bookmarks) serving students, professionals, and everyday customers in the Philippines. This is its landing page — the design should feel clean, modern, and friendly-professional.

## Always
- Always invoke the frontend-design skill before writing any front-end code.
- Reference `brand_assets/` for the logo, colors, and brand guidelines. The brand colors and tagline live in `brand_assets/brand.md`.
- Keep the design clean and modern.

## Stack
- HTML, CSS, and vanilla JavaScript. No framework.
- Deploy on Vercel via GitHub auto-deploy.

## Never
- Use placeholder Lorem Ipsum text.
- Ship designs that look "AI vibe coded": generic gradient stock backgrounds, fake stats, or badge-and-pill templates with no real content.
- Modify any files in `brand_assets/`.
